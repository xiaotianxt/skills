# Repository Instructions

`~/dev/skills` is the canonical source tree for user-owned agent skills.

After completing any coherent change, immediately update every affected skill,
reference, source map, and governance document; run the relevant validation;
and create one atomic Git commit. Do not leave completed work uncommitted, and
do not combine unrelated changes in the same commit.

Use the normal signed-commit flow. Do not bypass signing, amend existing
commits, or push unless the user explicitly asks.
